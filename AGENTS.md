# AGENTS.md

Teaching repo for the XII EMMSB 2026 course "Energia Livre de Ligação e Caracterização do Reconhecimento Molecular por Cálculos Quânticos" (MOPAC-based). Docs and datasets; the only build tooling is the Sphinx site (`docs/`, GitHub Pages).

## Structure
- `draft.txt` — the instructor's day-by-day outline; source of truth for course content.
- `D01`–`D04` — one folder per course day (D01: PDB/MOPAC file formats, protonation; D02: small molecules, ΔE × electron sharing; D03: BACE-1 protein–ligand, ΔG × BSI correlation; D04: plots — 3D, heatmap, per-orbital). `D0X/index.md` files are empty placeholders to be filled in.
- `D02/` — small-molecule (AcOH–uracil dimer, S66 #22) dissociation-curve day. `D02/01_preparation.md` (dimer inputs at 6 distances, filled in) and `D02/02_run_IEDA.md` (IED via `IEDA two_sel`, chain A × chain B, fills `D02/scores_S66.csv` IED column, filled in). Data: `D02/data/xyz/`, `orca_inp/`, `pbds/`, and MOPAC results per distance in `D02/data/AcOH_Uracil_result/` (`.mop`/`.out`/`.aux`/`.arc` — templates for the IEDA `--qm`).
- `D03/data/<pdb>/` — one folder per BACE-1 complex: `*_qm.mop` (MOPAC input) + `*_qm.pdb` (MOPAC 2016 output). Systems: 3bra/AEF, 4ha5/13W, 4h3g/10Q. Tutorials: `D03/01_preparation.md` (PDB → `.mop`, filled in) and `D03/02_run_IEDA.md` (IED between chain A and ligand chain X via `IEDA two_sel`, filled in).
- `D03/scores_BSI*.csv` — experimental ΔG (computed from kd/ki) vs IEDA (electron sharing), with R² in the last row. `scores_BSI_results.csv` is the raw template (IEDA=0, R²=0); `scores_BSI.csv` holds the computed values.
- `docs/` — Sphinx site (pt-BR, MyST, theme `furo`) deployed to GitHub Pages by `.github/workflows/docs.yml`. One page per course day (`docs/dias/d0X.md`); day pages `{include}` the canonical markdown from `D01`–`D04` inline (no duplication, no separate tutorial pages). `docs/dados.md` renders the CSVs via `csv-table :file:` relative to the `docs/` source root.

## Conventions
- All course content is written in Brazilian Portuguese — keep new text in pt-BR.
- `.mop` inputs use the semi-empirical header `PM6-D3H4 ALLVEC VECTOR LARGE MOZYME eps=78.4 PDB 1SCF AUX` (implicit water at eps=78.4). Keep header lines untouched.
- Commit messages are short, often a single word (e.g. "dias", "data pdbs").

## Gotchas
- `README.md` (title only) and `installation.md` (empty) are stubs, not real docs.
- IEDA and MOPAC are not installed in this environment; the D03 tutorials are instructional only — `--qm` files (`*.aux`) are generated by running MOPAC on the `.mop` inputs and are not versioned.
- The data folder currently lives at `D03/data/` (scores at `D03/`); both were moved from the repo root — the old root copies are deleted in git but the moves are uncommitted.
- Local docs build: `pip install -r docs/requirements.txt` then `sphinx-build -b html docs docs/_build/html` (works with the installed Sphinx 9/myst-parser 5). `docs/_build/` is gitignored; the CI workflow rebuilds on push to `main`.
